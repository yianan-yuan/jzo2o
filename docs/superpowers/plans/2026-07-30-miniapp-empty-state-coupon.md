# 小程序空状态与优惠券视觉改造 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the mini-program home empty-state monkey illustration and refresh the draggable coupon entry and popup without changing coupon business behavior.

**Architecture:** The home page keeps its existing empty-state condition and only swaps the referenced transparent project asset. `ExpBall.vue` remains the isolated coupon entry component, but replaces the embedded raster-red-packet presentation with scoped template and SCSS primitives while retaining the existing navigation path.

**Tech Stack:** Vue 3 `<script setup>`, uni-app, scoped SCSS, Node built-in test runner, built-in image generation and local chroma-key removal.

## Global Constraints

- Keep `!city.name || menuData.length === 0` and the existing city-selection action unchanged.
- Do not change coupon data, discount values, APIs, or `/pages/coupon/index`.
- Retain draggable coupon entry behavior and restore the entry when the popup closes or routes to the coupon page.
- The generated empty-state asset must be transparent and contain no people, animals, robots, text, logos, or monkey imagery.
