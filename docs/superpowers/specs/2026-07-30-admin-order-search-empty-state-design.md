# 管理端订单筛选与空状态修复设计

## 目标

让订单列表可按完整或部分客户电话查询；服务记录不再显示无效时间；暂时隐藏不需要的菜单，并替换带猴子的空状态图。

## 方案

- 后端将客户电话条件改为去除首尾空格后的 `LIKE` 查询；空字符串不参与筛选。
- 服务记录卡片仅在存在实际开始服务时间时显示；结束服务时间为空时显示 `-`。
- 从路由配置中注释评价管理和企业管理两个顶级路由，保留原页面代码。
- 公用空状态组件使用新的无角色家政工具箱插画。

## 验收

- 输入手机号全号或后几位能命中对应订单。
- 缺少服务记录的订单详情不出现 `NaN`。
- 侧边栏不显示评价管理、企业管理。
- 所有表格空状态不再显示猴子图案。
