# 移动端页面重做纠偏设计

## 目标

恢复服务人员 App 使用 HBuilderX 自带 UniApp 工具链的可运行状态，并将用户小程序从“全局换色”调整为逐页、可验证的暖橙安心视觉重做。

## 构建恢复

- 服务人员 App 不提交本地 `node_modules`。
- 删除误装的旧版 `@dcloudio/vite-plugin-uni`，让 HBuilderX 使用自身匹配的构建器。
- 不修改现有 API、路由、页面配置或业务数据流。

## 小程序视觉范围

### 首页

- 保留城市选择、搜索、服务分类、推荐服务、底部导航和浮球入口。
- 采用米白页面底色、暖橙渐变头部、白色圆角搜索框和 2 列服务卡片。
- 推荐服务改为独立白卡：服务图、标签、名称、价格与主操作按钮层级清晰。

### 我的

- 恢复原背景图层，不再由全局 `background` 覆盖。
- 个人信息置于暖橙渐变头部，订单和功能入口使用独立白色圆角卡片。
- 保留登录、订单、地址、优惠券、评价和客服电话的既有交互。

### 其余业务页

- 服务、搜索、订单、地址、优惠券、支付、消息、城市等页面仅通过各自页面或共享组件样式接入主题变量。
- 禁止以带 `!important` 的全局页面背景、卡片和按钮选择器覆盖业务页局部样式。

## 实现边界

- 移除上次在两个 `App.vue` 中添加的广泛业务选择器覆盖层。
- 主题变量与已改造的通用导航、标签组件继续保留。
- 为首页、我的页和全局覆盖回归分别增加源代码契约测试。

## 验收

- 服务人员 App 在 HBuilderX 中不再加载项目本地旧版 Vite 插件。
- 小程序首页的搜索、分类和推荐服务清晰可见；“我的”页头像、昵称和订单卡片不再出现白字/空白。
- 两端既有 Node 测试通过，且小程序新增的页面样式契约测试通过。
