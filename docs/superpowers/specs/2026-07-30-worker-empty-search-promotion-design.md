# 服务人员空状态、搜索布局与首页优惠图修复设计

## 目标

完成三项彼此独立但视觉一致的移动端修复：服务人员 App 不再显示猴子空状态图，小程序搜索框恢复到导航栏下方，小程序首页活动更换为日常保洁 1 元优惠。

## 服务人员 App 空状态

`components/empty/index.vue` 保持现有 `canPickUp` 状态分支，不改变抢单接口或列表数据。将旧的 `static/new/empty.png` 背景替换为页面原生的“订单雷达 + 工具箱待命”插画：暖橙主色、雷达圆环和工具箱勾选标记。可接单但无数据时显示“暂时没有符合条件的订单，保持在线，机会很快到来”；未开启接单时保留原有业务提示。

## 小程序搜索布局

根因是 `styles/warm-business.scss` 的共享选择器把 `.searchBox` 与业务页容器一同设为 `min-height: 100vh`。搜索盒因此在 flex 交叉轴居中，落在屏幕中部。

修复只在搜索页生效：覆盖搜索盒的最小高度为自动值，并给结果容器使用明确的可用视口高度。保留前一轮已修复的“确认搜索才请求、城市校验、历史记录安全读取”逻辑，不修改接口或服务详情跳转。

## 日常保洁优惠横幅

使用 ImageGen 生成一张无文字的暖色家居保洁营销背景图，保存为小程序静态资源的新文件，不覆盖原 `banner.png`。首页横幅改为使用该资源，并以页面文本覆盖展示：

- 标题：`日常保洁限时优惠价`
- 价格：`¥1`
- 辅助文案：`专业保洁上门服务，限时优惠`

文字由页面渲染，以确保中文和价格准确；图片只承担人物、家庭环境与氛围表达。点击行为保持当前首页横幅无跳转的行为。

## 验收标准

1. 服务人员首页空订单时不再引用或展示猴子空状态图片，出现订单雷达与工具箱待命图形。
2. 小程序搜索页打开后，输入框紧邻导航栏；不占据整屏高度，搜索结果区域可滚动。
3. 首页活动横幅不再引用 `banner.png`，展示“日常保洁限时优惠价 ¥1”及新生成的保洁场景背景。
4. 两端静态界面契约测试通过；服务人员 App H5 构建通过。
