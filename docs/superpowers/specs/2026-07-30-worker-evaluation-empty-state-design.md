# 服务人员评价空状态设计

## 目标

修复服务人员 App“我的评价”页在无数据时复用抢单空状态、显示订单图案与订单文案的问题。

## 方案

通用 `Empty` 组件新增仅页面展示使用的 `variant` 属性：默认 `order` 保持现有抢单和订单页行为；评价页传入 `evaluation`。评价变体展示星级评价和对话气泡图案，文案为“暂无评价记录，完成服务后，客户的评价会出现在这里”。

## 边界

- 不修改评价列表接口、筛选 Tab、分页与底部导航。
- `pages/index`、`pages/pickup`、`pages/history` 不传新属性，继续使用现有订单空状态。
- 以静态合约验证评价页传入变体，组件同时包含评价文案且默认订单行为仍存在。
