# 悦家服务全端品牌清理设计

## 目标

将 GitHub 仓库内面向用户、运营人员和项目阅读者展示的旧品牌统一为“悦家服务”，并移除登录页的培训提示。同时修复小程序服务条款弹窗遮挡确认按钮、导致无法登录的问题。保持现有业务、微信与支付相关技术配置不变。

## 品牌规则

- 服务人员 App 使用“悦家服务 · 服务端”。
- 小程序使用“悦家服务”。
- 管理端使用“悦家服务 · 管理端”。
- 管理端版权统一为 `Copyright © 2026 悦家服务. All Rights Reserved.`。
- 不再展示“仅用于 IT 培训教学使用”的红色提示。
- 登录页和管理端侧栏不再引用包含旧品牌文字的位图，改为可维护的代码品牌标识和文本，防止旧名称随图片残留。

## 修改范围

1. 小程序登录页：替换旧 logo 显示；服务条款正文可滚动，底部“不同意 / 同意并继续”固定可见；同意后继续现有微信登录流程。
2. 服务人员 App 登录页：替换旧 logo 显示、删除培训提示及无用样式。
3. 管理端登录页：替换旧 logo 显示、删除培训提示、更新登录页版权和浏览器标题。
4. 管理端侧边栏：在展开与收起状态下均显示悦家服务的代码品牌标识，不再使用旧 logo 图片。
5. 管理端通用页脚：更新两种布局中的旧 Tencent 版权。
6. 管理端用户可见的示例通知：把“腾讯大厦”替换为“悦家服务中心”。
7. 项目 README 与文档站标题、封面介绍：更新为悦家服务管理端；不再保留旧项目名称作为对外标题。

## 小程序登录根因与修复边界

`pages/login/index.scss` 将服务条款弹窗包装层固定为 `500rpx`，同时使用了较大的上下内边距。服务条款正文和操作区合计超出可视区域，导致“不同意 / 同意”按钮落在弹窗之外。

修复只调整该弹窗的布局：包装层改为基于视口的最大高度，正文单独滚动，操作区固定在底部。不会跳过服务条款，也不会更改 `wx.login`、用户信息读取、登录接口、令牌缓存、城市定位或跳转逻辑。

## 明确保留

以下是技术实现、第三方集成或历史组件路径，不属于产品品牌，因此不修改：

- 后端 `tencent.wechat` 配置及 `com.jzo2o.thirdparty.tencent` 包名。
- TDesign/Tencent 第三方文档链接、uni-ui 更新日志。
- `czriComponents` 的目录名、导入路径和字体技术名称。

## 验收与验证

- 静态扫描不再在运行时页面、管理端入口或项目文档中找到“云岚到家”“云岚家政”或培训提示。
- 小程序点击“快速登录”后，服务条款底部操作区始终可见；点击“同意并继续”会调用现有登录函数。
- 服务人员 App 与管理端的现有静态 UI 合约测试继续通过，并补充品牌断言。
- 管理端执行 `npm run build`；服务人员 App 执行现有 H5 构建或说明受本机 HBuilderX 环境限制的结果。
- 不修改 API、路由、登录鉴权及第三方服务配置。
